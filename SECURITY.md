# Security policy

## Reporting a vulnerability

Report a suspected vulnerability through GitHub's
[private vulnerability reporting](https://github.com/hniedner/datatables-backend/security/advisories/new), which is
enabled and the preferred channel, or by email to <hannes@niedner-consulting.com>. Please do not open a public issue or
pull request for it.

Include:

- the version of datatables-backend (or the commit, when you run from source);
- the backend and the database or search engine behind it, with their versions;
- a minimal request that shows the problem;
- the impact you see.

## Supported versions

Only the latest release on PyPI receives security fixes.

## What to expect

You get an acknowledgement, and then either a fix or an explanation of why the report is not treated as a
vulnerability. Disclosure is coordinated with you: please keep the details private until a fix is released.
